# Ask Gina (askgina.ai) vs Tocker — 2026-10-06

Research via search snippets only; askgina.ai and directory pages were not reachable from the research environment. Spot-check before quoting.

## What it is
- "Your onchain concierge — chat to trade Polymarket and automate strategies across 12+ chains." Also Hyperliquid perps.
- Chat-first: ask in plain English; it searches Polymarket, places the bet, tracks the position, reviews PnL.
- "Recipes": describe a strategy and Gina writes code that runs on a schedule or trigger, 24/7.
- Wallet: Privy self-custodial EVM + Solana wallet with delegated execution; gas sponsored.
- Pricing: credit packs, $10 per 5M credits up to $60 per 30M.
- Company: TYBB Labs, led by Sid Shekhar; backed by Prelude and Coinbase Ventures. Came out of a hackathon; a co-founder previously sold a crypto data company to Coinbase.
- No public traction or funding amount found.

Sources: askgina.ai; polymart.app/ask-gina; pm.wiki/projects/ask-gina; clawskills.sh/skills/sidshekhar-askgina-polymarket (via search results).

## How Tocker differs
| | Ask Gina | Tocker |
|---|---|---|
| Model | Chat assistant you instruct; recipes automate | Autonomous agent built around a strategy |
| Discovery | You ask for markets/tokens | Sweeps every new launch, scores 0–100 |
| Safety | No enforced token gates found | 10 hard gates; exits in code every 5 min |
| Data | Not found to buy paid data | Pays per call over x402 (sentiment, smart money, sell checks) |
| Social | No public record/feed found | Public verified record, private strategy, creator payouts |
| Markets | Polymarket, 12+ chains, Hyperliquid | Solana + Base memecoins now; Polymarket and tokenized stocks next |
| Pricing | Prepaid credits | 20 bps per trade |

## Threat
Same rails (Privy), Coinbase-backed, and already live on Polymarket, Tocker's planned expansion market. Answer: Tocker is agent-first with enforced safety and a public record that powers distribution; Gina is a chat concierge.
